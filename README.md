# HSU YAMIN HTIKE Portfolio

[English](#english) | [日本語](#日本語)

## English

The portfolio website of Hsu Yamin Htike, a Graphic Design student at Kobe Denshi (神戸電子専門学校), originally from Myanmar. It presents web design, graphic design and video work. The site text is in Japanese.

### Pages

| Page | File |
|---|---|
| Home | `index.html` |
| Profile | `profile.html` |
| Works | `works.html` |
| Aquarium website | `work-aquarium.html` |
| School information banner | `work-school-banner.html` |
| Art and Human exhibition poster | `work-art-human.html` |
| Bibimbap recipe video | `work-bibimbap.html` |
| Scent of Memory ZINE (香の記憶BOOK、ZINE) | `work-zine.html` |
| Contact | `contact.html` |

### Built with

- Plain HTML and CSS, with no framework and no JavaScript
- Responsive layouts for desktop, tablet and phone
- Native HTML `popover` for enlarged images, and CSS scroll-driven animations
- Motion reduced for visitors who ask their device for less motion

### Run locally

```
python3 -m http.server 8934 --bind 127.0.0.1
```

Then open http://localhost:8934.

### 使用技術

- HTML と CSS のみ（フレームワークと JavaScript は未使用）
- パソコン、タブレット、スマートフォンに対応したレスポンシブデザイン
- HTML の `popover` による画像の拡大表示と、CSS のスクロール連動アニメーション
- 端末で「視差効果を減らす」などを設定している方には、動きを抑えて表示
